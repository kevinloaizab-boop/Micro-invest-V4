# MicroInvest V3 Starter
1. Sube estos archivos a un repositorio nuevo de GitHub.
2. En Vercel: Add New > Project > importa el repositorio.
3. Settings > Environment Variables > agrega ALPHA_VANTAGE_API_KEY con tu clave.
4. Redeploy.
La clave se usa solo en /api/market y no se incluye en el frontend.
